# בדיקות "כסף אמיתי" - החלום, ריבית דה ריבית, פנסיה

נולדו מהשוואה מול מחשבונים חיצוניים (17.11.26). כל בדיקה מריצה את `calc()` האמיתי מתוך הקובץ (צל-DOM ב-`shadow.js`):

    node tests/real-money/dream.test.js  dream/index.html
    node tests/real-money/ribit.test.js  ribit/index.html
    node tests/real-money/pension.test.js pension/index.html <עותק הגרסה הקודמת של pension/index.html>

מה הן שומרות:
- **החלום:** היעד בשקלים של היום, התשואה לפני אינפלציה, ההפקדה עולה עם המדד. ההפקדה החודשית שווה לחיפוש בינארי עצמאי, והגרף (בכוח קנייה של היום) נוגע ביעד בדיוק בשנה האחרונה.
- **ריבית דה ריבית:** חישוב חודשי מדויק (הפקדה בסוף כל חודש), שווה לנוסחה הסגורה; דמי ניהול מתחברים; שורת "בכסף של היום".
- **פנסיה:** המקדם זז עם גיל הפרישה (212 לאישה ב-65, 202 לגבר ב-67, צורה מטבלת ביזפורטל 2026), ומקדם מהדוח או שהוקלד ביד לא נדרס.
