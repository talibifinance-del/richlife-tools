# בדיקות למחשבון הרכב

להריץ את שתיהן לפני כל פריסה של `car/index.html`:

    node tests/car/tc.js    # התקרה חייבת להיות ההופכי המדויק של הפסיקה
    node tests/car/tf.js    # 600 צירופי קלט אקראיים

`tc.js` מוודא את החוק היחיד שמחזיק את הכלי: **רכב מתחת לתקרה לא יכול להיכשל**.
`tf.js` סורק קלטים אקראיים ומחפש קריסות, סתירות, NaN על המסך, והמלצה שעוברת
15% מהנטו. שתיהן חייבות לצאת עם אפס.

`ta.js` הוא רק הפיגום: צל-DOM שמריץ את `calc()` האמיתי מתוך הקובץ עצמו, כדי
שהבדיקה תמדוד את מה שבאמת עולה לאוויר ולא עותק שלו.
